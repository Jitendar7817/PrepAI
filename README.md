# 🚀 PrepAI - AI Interview Preparation Platform

PrepAI is an AI-powered interview preparation platform that helps students and job seekers prepare for technical interviews, coding rounds, HR interviews, and resume analysis using Google's Gemini AI.

---

### Frontend
https://prep-ai-six-jade.vercel.app/

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/Jitendar7817/PrepAI.git
```

## Install Frontend

```bash
cd client
npm install
npm run dev
```

## Install Backend

```bash
cd server
npm install
npm start
```

---

# 🔑 Environment Variables

## Backend (.env)

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
```

## Frontend (.env)

```env
VITE_API_URL=http://localhost:5000/api
```
